# Adaptive Vehicle Dashboard Simulator

## Project Overview

The Adaptive Vehicle Dashboard Simulator is an embedded systems project developed using the LPC2129 (ARM7TDMI-S) microcontroller to simulate the functioning of an intelligent vehicle dashboard.

The main objective of this project is to demonstrate how an automotive dashboard processes vehicle-related information and communicates important parameters to the driver through dashboard displays, indicators, and warning notifications.

The system uses embedded programming and automotive communication concepts to simulate the interaction between vehicle electronic systems and the dashboard.

# Communication Protocols

##  CAN (Controller Area Network)

CAN is an automotive communication protocol used for communication between electronic control units (ECUs).

In this project, CAN communication is used to represent the exchange of vehicle-related information between electronic systems and the dashboard.
## UART (Universal Asynchronous Receiver Transmitter)

UART is a serial communication protocol used for transmitting and receiving data.

In this project, UART communication is configured at 9600 baud rate for serial communication and monitoring.
